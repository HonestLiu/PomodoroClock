# 02 · 产品范围与桌面功能对照

## 产品原则

移动端需实现桌面现有业务能力的功能等价版本。视觉布局、导航和平台交互可调整；计时、任务、记录、统计、权限、账本、同步语义不可悄悄改变。桌面没有真实后端的占位功能仍保持占位，不得用虚构内容伪装已实现。

## 功能覆盖矩阵

| 功能域 | 移动端需具备的功能 | 平台实现要求 |
|---|---|---|
| 账户 | 注册、登录、忘记密码、改密码、头像上传/移除、昵称编辑、退出、数据清除、同步状态与手动同步 | 使用既有 PB 用户账号；token 安全存储；退出只清会话，不清本机业务数据 |
| 任务与清单 | 内置视图（今天、明天、本周、已计划、任务、已完成、记录）、自定义清单/清单夹、排序、默认清单、任务 CRUD、全部提醒/标签/优先级/重复字段、子任务、完成与归档 | 触屏菜单/拖动或等价排序；URL 使用系统安全外链确认；日期按本地时区 |
| 专注与休息 | 番茄钟、倒计时、正计时、暂停/继续/重置/跳过、任务关联、休息循环、全屏沉浸、结束反馈、恢复提示、声音与白噪音 | 原生音频焦点与中断处理；通知授权；后台行为必须遵守 iOS/Android 限制并显示真实状态 |
| 今日/时间面板 | 今日任务、统计、专注时间轴与快捷操作 | 用移动导航/底部面板替代桌面浮窗，不删功能 |
| 报表 | 日/周/月/年周期切换、前后期与日期定位、统计卡、趋势、小时/星期分布、清单/任务分布、热力、目标日历、任务状态概览 | 手势/可访问图表；沿用 `docs/05-modules/report.md` 的定义和验证口径 |
| 奖励中心/会员 | 金币、XP、等级、激励商店、等级奖励、基金、收支明细、估值规则、周/月会员二维码与订单确认流程 | 保持本地账本事务/幂等语义。二维码和待确认订单按当前 `growth_data` 规则进入共享快照；移动相册导入并校验图像。不可声称支付经过平台验证 |
| 任务线/纪念日 | 任务看板与目标、行动路线、接取和完成结算；倒数日创建、重复、提醒 | AI 离线/未配置提供手动规划；移动提醒用本地通知适配 |
| AI | 自然语言创建、任务拆解、每日计划、日报/周报、草稿预览/选择采纳/撤销、估时校准 | 复用既有 provider 能力和校验规则；API Key 只保存在本机安全存储；错误时可手工操作 |
| 通知 | 应用内通知、未读数、已读/全部已读、任务到时提醒、专注/休息/倒计时结束提醒 | 后台通知及时限按系统权限能力实现；通知内容不含敏感备注 |
| 搜索 | 全局任务/清单搜索、结果定位/高亮语义、键盘/屏幕阅读器支持 | 手机使用搜索页/覆盖层，支持清除和空结果 |
| 设置与外观 | 通用、计时、通知、AI、账户、外观、关于等桌面设置；主题、语言、壁纸、白噪音、数据管理 | 设备项（服务器地址、API Key、权限、音频等）本机保存；共享偏好遵守同步白名单 |
| 桌面专属组件 | 独立悬浮计时球、托盘/菜单栏、macOS WidgetKit | 手机不复制桌面窗体；提供系统通知、桌面小组件（Android/iOS 各自可用时）及 app 内快速入口，核心计时操作不缺失。OS 小组件单列平台增强，不能阻塞核心发布 |

## 必须对齐的数据/业务语义

- 任务已完成归档与专注记录是两种不同对象和视图，不合并。
- 记录只统计 `phase=focus`；休息、倒计时自然结束和无效时长不能变成专注记录。正计时停止按桌面规则处理不足一分钟；番茄跳过保存实际有效时长。
- 统计必须按桌面模块的时间范围、时区、有效记录和目标达成定义复现，不在 UI 中自行猜算。
- 重复任务完成后按规则归档当前轮并创建下一轮；只完成一次，重试不重复创建。
- 删除任务保留专注记录并将关联置空；删除清单保留任务并置空归属；云端删除使用墓碑防止旧设备复活。
- 账户退出不清本地任务/记录；“删除数据”才清空本机业务数据和账本，并保持已播种标记避免重启回填演示数据。
- 奖励依据新归档专注事件幂等结算；删除历史记录不追回已发奖励。基金是本地预算账本；实际商品由用户自行购买。
- 同一计时会话不从一台设备同步接管到另一台。多设备计时冲突必须给出用户可见处理方式，不能同时在两端重复结算。
