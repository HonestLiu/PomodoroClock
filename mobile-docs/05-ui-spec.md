# 05 · 移动端界面与交互规格

## 总体导航

面向单手和小屏采用底部导航 + 页面路由。建议底部一级入口：**今天、任务、专注、报表、更多**。更多包含记录/已完成、清单与清单夹、任务线、倒数日、通知、奖励中心、搜索入口和设置。入口应可见且不超过两层；页面间打开弹层/二级页不能丢失计时状态。

专注屏有独立沉浸模式，但手势返回不得意外重置/结束计时。应用顶栏提供账号头像/同步状态、通知与快捷搜索；布局应避免机械复制桌面右上角图标。

## 页面规格

### 登录与账号

登录、注册、忘记密码、账号资料、头像/昵称、改密码、同步控制和退出。登录后首页先给同步/接管状态；首次多端数据不静默覆盖。退出后回访客本地模式，任务保留。危险“删除本机数据”需显示影响范围和二次确认。

### 今天

呈现今日待办、逾期任务、今日目标/专注摘要、当前计时状态和快速开始。今日视图包含符合桌面口径的逾期任务；任务来源清单可跳转。支持快速添加任务、完成、设日期和开始专注。

### 任务

提供全部、今天、明天、本周、已计划、自定义清单等桌面分类；归档分开显示“已完成任务”和“专注记录”。编辑字段沿用桌面任务字段：标题、备注、URL、日期/时间、紧急、重复、提前提醒、清单、标签、旗标、优先级、估时、父子任务。支持筛选、排序、完成、复制、移动、删除确认。长按/拖动排序需有明确落点和可访问替代操作。

### 专注

以大字显示模式、阶段、时长、关联任务。包含开始/暂停/继续/重置/跳过（按桌面模式语义）、切换番茄钟/倒计时/正计时、白噪音音色/音量、全屏沉浸与今日面板。前后台切换显示恢复横幅或结束反馈。结束前不因导航离开而丢状态。拒绝通知权限也可正常计时。

移动端显示后台能力状态：“计时可恢复；系统允许时通知提醒”，不能承诺无限后台运行。改变正在运行的计时模式/任务需确认或遵循桌面禁止覆盖规则。

### 报表

提供完整周期切换和桌面同一统计项。小屏采用卡片纵排；趋势图可触摸查看读数，图表同时提供列表/无障碍文字摘要。用户隐藏任务名时要对图表明细和 AI 报告同时生效。

### 奖励中心

Tab/分段为商店、等级奖励、基金与规则、流水。购买周/月会员或充值时显示金额快照、收款二维码与取消/确认；明确文字说明应用不会自动验证支付。恢复待确认订单时不自动确认、不展示错误金额。账本余额、商品和流水从同一个本地版本化状态生成。

### 任务线与倒数日

任务线提供目标创建、AI 规划/手动编排、预算、前置关系、可接取行动、完成结算；隐藏未解锁路线按桌面边界处理。倒数日单独建模，不作为普通任务，显示还有/已经/当天并支持重复及提醒。

### 通知、搜索和设置

通知面板区分未读，支持单条已读/全部已读。搜索可按任务/清单分组，选中后打开目标。设置提供通用、计时、外观、通知、AI、账户、关于，保留桌面所有字段；AI API Key 要遮蔽并仅存在安全本机存储。

## 状态与反馈

每页具备加载、首次空态、无结果、离线、同步中、同步失败、权限拒绝和重试状态。使用 SnackBar/局部反馈显示短操作结果，复杂数据接管或不可逆清除使用明确确认页。同步进度不得挡住正常离线操作。

## 视觉系统

遵守桌面中性色、番茄红、蓝色任务强调、浅色/深色主题和 FocusPomodoro 品牌图标。不能逐像素缩放桌面 UI；使用响应式间距、44dp 以上触控区、系统安全区、可滚动表单、系统字体缩放与语义 label。图表颜色在深色主题下仍需满足可读性。
