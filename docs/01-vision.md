# 01 · 产品愿景与范围

## 一句话
让"规划任务 → 预估番茄数 → 专注 → 归档 → 报表 → 达成每日目标"形成**本地优先、即时可感知**的闭环工具。

## 目标用户
考研/备考学生、知识工作者、自由职业者——需要任务规划 + 强制专注 + 数据反馈闭环的人群。

## 产品三面
1. **任务管理面**：多清单 + 按日期分类 + 已完成归档
2. **专注计时面**：番茄钟（专注/休息）+ 白噪音 + 全屏 + 悬浮小窗
3. **数据报表面**：专注统计 + 番茄记录热力图 + 清单分布 + 每日目标日历

## 成功标准（可度量）
- 一次完整闭环可在 3 步内完成：加任务 → 启动番茄 → 报表见数据（无需中途打断）
- 专注计时在关闭/重启后不丢失（§8.8-1 时间戳可靠计时）
- 全部核心功能离线可用，无强制联网
- 冷启动 ≤ 2s

## 非目标
- 云端/多设备同步、账号注册登录（原为预留 `users.email` 与导出能力）。**补充（2026-10）**：账户登录 + 单设备云同步已提前落地为可选对齐层，仍以本地为真相源、离线可用；多设备并发不承诺，见 `03-architecture.md` §账户与云同步。
- 团队协作、好友真实社交
- 移动端（Tauri mobile 为远期）

## 原则
本地优先（数据属于用户）、克制（不做功能堆砌）、反馈即时（数据变更立即反映在报表/角标）。
