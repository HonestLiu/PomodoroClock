## 阶段切换规则
- 每阶段结束必须全绿通过 `06-acceptance.md` 中该阶段的验收项。
- 一处不可妥协的**工程红线**：所有跨运行时改动必须同时更新 Rust SQL 与 TS 镜像，并跑通两份数据校验（见 `03-architecture.md` §数据一致性）。

## 建议立即执行（P1 第一步）
按依赖与性价比排序：
1. 任务更多菜单 + 移清单 + 删除（最小、高频、补齐 FR-T3 规格）
2. 全列表拖拽排序（P0 验收未强制，但观感提升最大）
3. 系统通知接线（让"番茄完成"真正弹系统通知）
4. 搜索回车定位高亮
