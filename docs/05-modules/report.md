# 模块 · 报表（report）

## 目标
按同一时间范围阅读专注投入、时间分布与任务目标，保持图表和明细合计一致。

## 当前界面（2026-10-30 重设计）

顶栏报表入口打开 `modals/ReportModal.tsx`。独立 `styles/report.css` 统一中性底色、番茄红趋势、图表标签和信息层级，不影响任务页统计卡。

- **统一周期**：默认本周；日/周/月/年、前后期、日期定位和回到本期。切换后整个报表同步更新；不保留原先不同面板各自的时间范围。
- **概览**：本期总时长、日均、次数、完成任务、专注天数；主趋势柱图与目标进展并排；补充平均/最长单次、最佳日、高峰小时、本期最长连续。底部单独标注累计时长、累计完成任务与当前连续天数。
- **时间分布**：清单环形图、任务时长明细（可隐藏任务名）、24 小时/7 星期分布。逐日×小时记录按需展开，支持年范围下独立滚动；历史周期不会把第一天误标成今天。
- **任务与目标**：锚点所在月份的目标日历，所选周期外日期淡化；本期完成任务列表。当前全部任务的完成率、待办/完成/逾期/今日到期/高优先级/预估番茄、待办投入、紧急/旗标，以及最近 5 条待到期任务，明确标注为当前快照，不随历史日期假装重建过去任务状态。
- **交互与适配**：周期使用原生单选，视图支持方向键/Home/End；主图与小时/星期柱可键盘聚焦读数。支持深色、英文和 390px 窄窗口，悬浮计时窗在报表打开时收起视图以免遮挡。关闭后计时状态不变。

## 数据模型与口径

`lib/report.ts::buildReport` 只接收 `dataStore` 中的任务、清单、专注记录，双运行时一致；不新增表或 Rust/TS 查询接口。

- 周从本地周一开始，日期边界复用 `periodRange`。`moveReportPeriod` 从周期起点导航，避免 1 月 31 日跳到 3 月、闰日跨年错位。
- 只统计 `phase=focus`、正且有限的时长、开始时间在周期内且不晚于当前时刻的归档记录。
- 与既有每日汇总一致：完整记录归属开始日期，时段归属开始小时，不在此报表中重新切分跨午夜记录。图表下方显示这一口径；网格各格为在对应日期/小时开始的记录总时长。
- 日均 = 总时长 / 所选周期截至今天已过去的自然日数，包含零记录日，不把未来天数纳入分母。
- 达标率保持既有口径：达标天数 / 有专注记录的天数，取整；未设置每日目标时不计算达标天数。
- 本期完成任务按 `completed_at` 落入周期计算，不按到期日推断。当前任务概览保持全量实时快照，单独注明范围。
- 任务、清单、日/小时/星期/月趋势和小时网格均由同一批记录聚合；未指定或已删除关联不会丢失时长。
- 日图 24 柱、周图 7 柱、月图对应月份全部自然日、年图 12 个月；零记录桶保留，避免无记录日被跳过。
- 目标日历显示该锚点月份，范围外日期淡化；年视图可通过日期定位选择需要查看的月份。

## 图表实现

- `charts/ReportTimeline.tsx`：原生按钮柱图，键盘/悬停读数，紧凑纵轴、每日目标参考线。
- `DonutChart`、`DurationList` 复用现有组件；不增加图表依赖。
- `PomodoroHeatmap` 修正真实今天标记，提示通过 portal 挂到 body，避免容器查询建立的布局上下文影响 fixed 提示位置。
- 容器查询控制概览/目标双栏和分布两栏的折叠；旧内核提供单栏媒体查询回退。动态视口单位保留旧单位回退。

## 验证

- `tools/verify-report.ts`：19 项，覆盖周/月/年边界、月底导航、闰年、跨年周、夏令时自然日、未来/无效/休息记录排除、空数据、日均、达标率、完成任务归属以及所有聚合合计。上海本地与 `America/New_York` 时区均通过。
- `tools/verify-report-ui.mjs`：真实 Chrome 中验证所有周期、日期跳转、空态、统一合计、三个视图、热力图今天标记、目标日历、键盘操作、深色/英文、650px/390px 和 Esc；截图在 `/tmp/report-*.png`。
- `tools/check-all.sh` 纳入报表纯逻辑检查；原有 `verify-data.ts` 的全局洞察/任务概览断言仍保留。
