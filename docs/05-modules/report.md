把专注/任务数据变成可行动的洞察：统计、趋势、分布、目标达成。

## 规则与口径
- 指标口径严格按 §7.2（见 `04-data.md`）。
- 周期统一 `day/week/month/year`，锚点为本地日期键；`shiftPeriod` 负责导航步进。
- 目标完成率=完成目标天数/专注天数（百分比取整；演示 70% 与算法 67% 的差异以算法为准，PRD §7.2 已注明）。
