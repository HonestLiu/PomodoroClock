# 模块 · 搜索（search）

## 目标
全局即时搜索任务/清单，回车定位并高亮目标。

## 当前状态
- ✅ 侧边栏搜索框聚焦弹出覆盖层；即时按任务名/清单名过滤，结果分组（任务/清单）。
- ✅ 回车定位 + 目标高亮；↑↓ 选择；Esc 关闭；⌘/Ctrl+K 或 / 唤起（`SearchOverlay.tsx:27-59`）。

## 规则
- 匹配：任务名/清单名义不区分大小写子串；结果按相关性（前缀优先）排序。
- **回车定位**（★）：默认选中首个结果 → 关闭覆盖层 → 路由到该任务/清单视图 → **任务高亮**（短暂底色闪烁 1.2s）。
- 全局快捷键：`⌘/Ctrl + K` 或 `/` 打开搜索（可达性 §9）。
