# 05 · 功能模块规范

每个文件定义**一个功能域**的可执行规格：当前状态、关键交互、规则、待办增量（★）、数据影响、验收标准与工作量估计。

| 模块 | 文档 | 优先级重心 |
|---|---|---|
| 任务管理 | `tasks.md` | P1：交互深度（菜单/排序） |
| 清单 | `lists.md` | P1：排序/默认清单 |
| 番茄钟 | `timer.md` | P1/P2：设置全量/恢复提示 |
| 报表 | `report.md` | P2/P3：趋势图/任务统计 |
| 设置 | `settings.md` | P2：i18n/深色/全量设置 |
| 通知 | `notify.md` | P1：系统通知接线 |
| 搜索 | `search.md` | P1：回车定位/高亮 |
| 倒数纪念日 | `countdown.md` | P2：独立日期域（自然日差/每年重复/提醒） |
| 成长/账户 | `growth.md` | P3/P4：成就/云同步 |
