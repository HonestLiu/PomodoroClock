# 桌面悬浮计时器（三种样式）

2026-11-01。独立桌面悬浮计时器，支持经典卡片、圆形悬浮球和极简长条三种外观。

## 体验

- 真正独立的 `desktop-orb` 桌面窗口，透明、无边框、置顶、不占任务栏项。三种外观共用同一个窗口和计时源。
- 设置 → 通用 → 悬浮计时器样式，三项原生单选，选择后即时保存并切换，重启后保留。默认恢复为经典卡片，旧配置无需迁移数据库；未知值回退经典卡片。

| 外观 | 可见主体尺寸 | 原生窗口尺寸（含透明阴影边距） | 内容 |
| --- | --- | --- | --- |
| 经典卡片（默认） | 200×118 | 216×134 | 原来的背景图、任务名称、时间/今日番茄数、播放/暂停；悬停显示打开和隐藏 |
| 圆形悬浮球 | 120×120 | 148×168 | 保留细进度环、状态、时间和播放/暂停；悬停显示打开和隐藏 |
| 极简长条 | 112×32 | 124×44 | 仅时间和播放/暂停；双击打开主界面，Esc 隐藏 |

尺寸为逻辑像素。样式切换会调整原生窗口大小并约束回屏幕可见范围，不保留旧样式的大透明点击区域；已经显示的窗口只调整大小，不重新 show 以免抢走设置单选组的焦点。

- 经典卡片背景跟随原有专注背景设置；未指定自定义图片时采用原来的海浪缩略图。大体积图片仅在变化时发送，计时快照不逐秒重复携带图片。
- 切换外观不重置计时、暂停状态或当前任务，不重新初始化铃声。
- 拖动球体移动窗口，双击球体打开主窗口的专注界面；按钮操作不触发拖动或双击打开。
- 专注与休息采用不同强调色，跟随主应用深浅色与语言。正计时显示累计时间，不制造虚假的目标进度。
- 主窗口关闭按钮改为隐藏，计时主进程继续工作；从球、菜单栏或 macOS Dock 可恢复主界面。彻底退出使用应用菜单或菜单栏的退出。
- 隐藏球不会暂停计时，可用顶栏番茄按钮、通用设置或菜单栏开关恢复。
- 浏览器版不能创建桌面窗口，对应开关禁用并解释仅桌面版支持，不再回退到应用内浮窗。`/orb.html` 是独立的设计预览入口。

## 单一计时源

- 主窗口中的 timerStore 仍是阶段切换、专注归档、结束铃声的唯一拥有者。
- `orbController.ts` 将受限快照发送到 Rust 缓存，再定向广播到球。快照不包含 API 密钥、账户、任务全集或奖励账本。
- `orb.html`/`orb.tsx` 是单独的 Vite 构建入口，不加载 App、timerStore 初始化、数据库或铃声模块。
- 球只发送 toggle/open/hide，主窗口执行；球不能直接写 timer_state、focus_records 或游戏任务。暂停等操作不主动展开主窗口，只有 open 会唤起主界面。
- 初始连接、结算中和主窗口长时间不响应时禁用计时操作，避免根据过期状态继续操作；重新收到快照后恢复。

## 原生与位置

- `src-tauri/src/orb.rs` 使用 Tauri 原生 WebviewWindowBuilder 创建透明置顶窗口。调用按窗口标签区分：只有 main 能发布快照和控制可见性，只有 desktop-orb 能请求球操作及保存自身位置。
- 球的能力文件仅授予监听/取消监听事件和拖动自身窗口，不复制主窗口的数据库、对话框、通知、自动启动等插件权限。
- 位置保存到应用数据目录的 `orb-position.json`。在物理像素坐标下保存，恢复时考虑显示器的缩放和工作区；支持副屏负坐标，移除显示器、改变分辨率或切换为更大的样式后，会按新尺寸将窗口约束回可见区域。
- 启动/显示不请求主窗口焦点，避免仅显示悬浮球时中断其他应用。

## 验证

- `node tools/verify-orb-ui.mjs`：独立透明入口、环形进度、开始/暂停/打开/隐藏命令、暂停时间冻结、主题及语言、原生拖动请求，以及没有业务持久化或第二个 timer owner。
- `node tools/verify-float-styles-ui.mjs`：设置默认值、三项单选及键盘切换、重启保留、计时状态不变、写入失败回滚与恢复、深浅色。
- `cargo test --test queries floating_timer_styles_default_to_classic_and_round_trip`：三种偏好持久化及无效值回退。
- `cargo test --lib orb::tests`：位置恢复在普通、副屏负坐标和小工作区的边界处理。
- 原生 macOS 使用测试构建验证：球独立显示、开始/暂停、打开主界面、两窗口时间一致、主窗口关闭后球保留、拖动后位置文件保存。三种外观均通过原生设置切换，暂停时间始终为 24:48；极简长条的实际原生窗口为 124×44 逻辑像素。未替换正式安装版。其他系统的桌面置顶行为未实机验证。
