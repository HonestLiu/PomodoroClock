# 模块 · 清单（lists）

## 目标
用户自定义清单的组织与管理：排序、默认清单、重命名、删除；配合任务分类角标。

## 当前状态
- ✅ 创建（侧边栏行内 + 设置页）、重命名、删除（任务归未指定）。
- ✅ 清单视图（`/lists/:id`）展示该清单未完成任务 + 统计卡。
- ✅ 排序（侧边栏拖拽重排，持久化）；✅ 默认清单概念（设置页标记 + create_task 识别）【P1 已完成】

## 关键规则
- 侧边栏清单区展示顺序 = `lists.sort_order ASC`。
- **清单排序**（★）：侧边栏清单可拖拽重排；键盘等价为清单行 `Alt+↑/↓`（`components/Sidebar.tsx`，行上有 `a11y.reorderHint` 提示）。排序持久化 `lists.sort_order`。
- **默认清单**（★，P2）：设置「清单管理」中标记某清单为默认；新建任务默认落入该清单（当前逻辑取 `sort_order` 最小者，改为显式默认）。
- 重命名/删除保持现状；删除时二次确认提示"任务将归未指定"。
